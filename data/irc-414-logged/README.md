# IRC 414 Logged Archive

Structured browser-readable archive generated from the Telegram Desktop export
IRC 414 atropa_logged.

- Runtime manifest: manifest.json
- Message chunks: chunks/*.json
- Referenced media: media/
- The main game HTML does not embed this archive.
- The in-game phone loads chunks on demand.

The original message text and IDs are preserved. nick/body are convenience
fields extracted from IRC-style [nick] message lines; text remains the
original displayed Telegram-export text.
