# Font provenance — Stage 0 review

BT Beau Sans is designed by BeauType Studio. Original Light (300), Regular (400), Medium (500), Bold (700) and ExtraBold (800) OTF files were downloaded without modification from the creator's public folder linked by [BeauType](https://beautype.studio/bt-beausans). The creator's [project page](https://beau.vn/en/our-projects/bt-beau-sans-typeface-empowering-the-sense-of-technology) describes it as a free typeface with a standard commercial license. Download provenance and SHA-256 checksums are in `docs/FONT_PROVENANCE.json`; there is no license file in the public folder. Retain attribution and obtain/archive the complete license for the final release package.

Soloist Extra Italic is by Daniel Zadorozny / Iconian Fonts. The original TTF and terms are from the author's [Soloist archive](https://www.iconian.com/fonts3/soloist12.zip); no modification, conversion or subsetting was performed. `SOLOIST-TERMS.txt` is preserved verbatim. The [author's terms](https://www.iconian.com/commercial.html) permit free distribution and noncommercial use; commercial use requires the author's consent and applicable license fee. This local S0 review uses the original font. Commercial release clearance remains an S7 packaging requirement; no payment or contact has been made. The code declares system fallbacks in case either font fails to load.

The live site serves BT Beau Sans 2.000 and Soloist 1.1; this review serves Beau's original 2.000 and Iconian's public Soloist 1.2 archive. Both family, weight and Extra Italic design are identified from the live styles; the minor Soloist version difference is recorded rather than hidden.
