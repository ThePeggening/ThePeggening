# PCOCK: Feathers of Liberty — Liberty Valley beta

Build: PCOCK-VALLEY-BETA-20261001-r9. Includes the complete guided seven-chapter Valley campaign,
Fishing/Woodcutting and the completed optional Liberty Runner and Ghost Route.
Unfinished Peg Keeper is excluded. All three playable games use the same attached,
animated 3D peacock tail. R9 fixes keyboard movement after menus/Settings.

## Upload the game files

Extract the ZIP and put its contents at your repository root. index.html,
shared/, assets/, libs/, games/ and .nojekyll must stay together.
The ZIP has no enclosing build folder. Upload the extracted files rather than only
the ZIP. The game runs on a static HTTP/HTTPS host, including repository subpaths.
Choose hosting/publication yourself after the checks in CHECK_RELEASE_LATER.txt.
This release was prepared locally; no repository was accessed or published.

## Play locally

Install Node.js, then open PLAY.cmd or run node tools/serve.mjs from this folder.
Visit http://127.0.0.1:8080/pcock/ . Keep the server window open. See README-FIRST.txt
for controls, activities and reset/restore. Opening index.html as a file will not
load the game. The production static host needs no Node.js, backend or service worker.

## Saves and review

Saves belong to this browser and origin; a new hosted address starts its own save.
Start Over creates a local recovery backup before resetting. The Sol 5.6 handoff
prompt is a separate delivery and is deliberately absent from this package.
RELEASE_MANIFEST.json lists SHA-256 hashes for every payload file.
Physical-phone testing, human story/feel review, font clearance and publication
remain deferred. Graphics/assets are retained; supplied originals are unchanged.
